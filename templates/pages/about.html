Acerca de TechBlog

TechBlog es una aplicación web de blog desarrollada con Django como proyecto final del curso de Python de Coderhouse. El objetivo del proyecto fue aplicar de forma integral los conocimientos adquiridos durante el curso: modelos y migraciones, vistas basadas en clases, formularios con validación, autenticación de usuarios y administración de contenido.

La aplicación permite a cualquier usuario registrarse, crear publicaciones sobre programación y tecnología, comentar las publicaciones de otros usuarios, y gestionar su propio perfil.

Tecnologías utilizadas

  • Python 3 y Django
  • SQLite (desarrollo) / PostgreSQL (producción)
  • Bootstrap 5 para la interfaz
  • WhiteNoise para servir archivos estáticos en producción
  • Render para el despliegue
